# ChipJTAG Pro Closed Beta v0.3.0

Release date: 2026-08-20

## Update list

- Packages is now a visible top-level entry. The bundled CPU Boundary I/O and
  Waveform Compare packages can be installed, opened, removed and reinstalled
  locally. This build does not download package payloads from the network.
- Waveform Compare provides independent upper/lower file loading, scrolling
  and zoom. The panes lock only after marker or label alignment is selected.
- CPU Boundary I/O can load a local BSDL and show bounded read-only engineering
  JTAG events, including TX/RX/CHECK, bit counts, topology, IDCODEs and both
  successful and failed stages. Official supported CPU model count remains 0.
- Settings contains the software updater. The Stable Closed Beta channel
  downloads the direct EXE asset, verifies its SHA-256, then uses the local
  replacement/restart helper.
- Input traces remain blank until the first observation. A BSDL `output3`
  disable-control cell can decode high impedance and render `Z` as a dashed
  trace without manually selecting pin type Z.
- A bounded Case-scoped support submission/chat surface is included for
  approved endpoints configured by the operator. No support URL, bearer token,
  customer BSDL or customer identifier is embedded in the executable.

The two ignored tests require explicit owner-local BSDL paths or the generated
5,306-pin scale fixture. They are data-dependent gates, not hidden failures.

## Important limitations

- This Closed Beta is not Authenticode-signed. Windows may show Unknown
  publisher or SmartScreen warnings.
- CPU Boundary I/O is an engineering preview. The official model registry is
  empty, and local BSDL/ID/capture results do not select or certify a CPU model.
- Physical adapter/target behavior is not proven by software tests alone.
- General stable `<= 1 ms` capture and every multi-device chain are not claimed.
- The support/debug UI requires an approved endpoint and token supplied at
  runtime; the release does not provide a public unrestricted remote-control
  channel.
