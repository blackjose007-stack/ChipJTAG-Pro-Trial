## 中文更新清單

這是 ChipJTAG Pro `v0.2.8` Windows x64 封閉測試版。`v0.2.5` 無法匯入本版
簽發的 `.cjlicense`，已取得三個月授權的測試者請升級至本版。

- Settings 顯示 Device ID，並提供 Copy 按鈕，方便提交授權資料。
- 可匯入綁定 Device ID、email 與到期日的簽章 `.cjlicense`，離線啟用 Pro。
- Pin List 新增 Waveform `All` / `None`，只調整可顯示波形的 pin。
- 波形圖可用滑鼠拖曳選取時間範圍並局部放大。
- 新增 Rising、Falling、Either 軟體邊緣 trigger；觸發後停止掃描、保留波形並顯示標記。
- 固定 Pin List 捲動區高度與背景清除色，降低上下捲動時偶發紅色表格框閃爍。
- 保留既有 BSDL、LPF/XDC、JTAG scanner、recording、export 與 terminal 行為，並完成自動化回歸測試。

## English Update List

- Added a Device ID Copy button in Settings for license requests.
- Added signed `.cjlicense` import for offline, device-bound, email-bound Pro access with an expiration date.
- Added Waveform All/None controls for waveform-capable pins.
- Added drag-to-zoom for a selected waveform time range.
- Added Rising, Falling, and Either software edge triggers. A trigger stops scanning, preserves the capture, and displays a marker.
- Stabilized the Pin List scroll body and native background clearing to reduce intermittent red table-border flicker while scrolling.
- Kept the existing BSDL, LPF/XDC, scanner, recording, export, and terminal paths under automated regression coverage.

## Important Limitations

- This Closed Beta is not Authenticode-signed. Windows may show Unknown publisher or SmartScreen warnings.
- The checks above are software, packaging, simulation, and launch validation. They do not prove customer-board or physical-adapter behavior.
- AMD/Xilinx cable and target acceptance is not complete.
- General stable `<= 1 ms` physical capture is not claimed.
- Long-duration recording still requires physical endurance verification.
- Advanced Automation CLI/Tcl and enterprise functions are not included.

## Evaluator Rules

1. Download only from this GitHub Release.
2. Verify the complete SHA-256 before extraction.
3. Use a non-production test board and a known-good BSDL.
4. Do not publish customer BSDL, pin maps, waveforms, diagnostics, serial numbers, Device IDs, email addresses, or license files in a public Issue.
5. Report the adapter, vendor-tool version, target family, observed error, and sanitized Interface Log excerpt.
