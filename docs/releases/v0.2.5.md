## 中文摘要

這是 ChipJTAG Pro `v0.2.5` Windows x64 公開預覽試用版，提供首次成功啟動後
七天的 Pro evaluation。本次發布固定驗證既有功能，不包含 Advanced
Automation、CLI/Tcl extension 或 Enterprise 功能。

請只從本 Release 下載，並在解壓縮前核對完整 SHA-256。本預覽版尚未進行
Authenticode 簽章，Windows 可能顯示 Unknown publisher 或 SmartScreen 警告。
AMD/Xilinx 實機驗收、通用穩定 `<= 1 ms` capture，以及長時間錄製穩定度仍在
驗證中。

## Validation Scope

- Native Windows launch and seven-day trial status.
- Adapter discovery and connection.
- BSDL import and physical IDCODE gate.
- Start/stop scan and Interface Log diagnostics.
- Existing waveform display and navigation.
- `.cjwave` save/load fidelity.
- Snapshot, CSV, VCD, Evidence, and Diagnostics exports according to trial
  limits.

## Important Limitations

- This public preview is not Authenticode-signed. Windows may show Unknown
  publisher or SmartScreen warnings.
- The packaged developer README references internal documentation paths that
  are not included in the archive. Use this public repository for the current
  installation, SOP, validation, and troubleshooting documents.
- AMD/Xilinx cable and target acceptance is not complete.
- General stable `<= 1 ms` physical capture is not claimed.
- Long-duration recording still requires physical endurance verification.
- Multi-device AMD/Xilinx waveform capture is outside the v0.2.5 acceptance
  scope.
- CLI/Tcl automation and enterprise functions are not included.

## Evaluator Rules

1. Download only from this GitHub Release.
2. Verify the complete SHA-256 before extraction.
3. Use a non-production test board and a known-good BSDL.
4. Do not publish customer BSDL, pin maps, waveforms, diagnostics, serial
   numbers, or other confidential hardware data in a public Issue.
5. Report the adapter, vendor-tool version, target family, observed error, and
   sanitized Interface Log excerpt.
